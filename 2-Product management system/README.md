# 📦 Product Management System (Bash)

An interactive command-line (CLI) inventory management tool built with **GNU Bash**, featuring pass-by-reference array operations, duplicate validation, and discount filtering.

## ✨ Key Features
* **View All Products:** Displays all products along with their prices and discount percentages.
* **Add New Product:** Validates duplicate names before adding new items to the inventory.
* **Filter by Discount:** Displays products offering a discount equal to or greater than the entered percentage.

## 🚀 How to Run
```bash
chmod +x product.bash
./product.bash
